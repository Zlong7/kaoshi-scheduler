# 高校期末考试排考优化 (Exam Scheduling Optimization)

## 项目简介
本项目将排考问题抽象为图着色问题，使用贪心算法求上界，并使用回溯法与分支限界法求解最少时间段及合法排考方案。

## 环境依赖
- Python 3.8+
- 安装依赖：`pip install -r requirements.txt`

## 运行说明
请在项目根目录下运行以下命令：

1. **运行主程序** (测试数据):
   `python main.py data/toy6.txt --algo all`
2. **边界测试** (包含Toy6、空图、完全图、二部图、含孤立点、非法方案校验):
   `python -m src.test_edge`
3. **生成可视化排考日历**:
   `python -m src.visualize`
4. **批量实验与绘图**:
   `python -m experiments.run_all`
   `python -m experiments.plot`

## 数据与实验说明
- **数据格式**：第一行 `n m` (课程数 和 冲突边数)，随后是 `m` 条边。
- **随机图实验设定**：边概率 \(p=0.3\)；每个规模测试 5 张图；固定随机种子为 `Run_ID * 100 + n`。
- **超时机制**：统一设置 30 秒超时上限。CSV 中 `Nodes=-1` 代表超时。
- **统计口径**：
  - 耗时为包含所有运行（超时按 30s 截尾计入）的平均值。
  - 节点均值为**仅限成功样本**（`Nodes != -1`）的平均值。
  - 回溯法节点指**递归调用总次数**（累计尝试所有K）；分支限界节点指**出堆扩展次数**。
